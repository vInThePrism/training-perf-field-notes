# Additional training observations

These supplements preserve distinct source observations that do not fit the longer numbered cases. Their timings belong to their original experiments and have not been independently reproduced by the repository reorganization.

- [Additional training cases](additional-training-cases.md): host synchronization, NFS JIT caches, packing masks, moving OOMs, dependency conflicts, restart hangs, and data preparation.
- [Lessons from training jobs](lessons-from-training-jobs.md): memory offload, gradients, measurement, and connections back to GPU execution.
- [Data pipeline and recovery evidence](data-pipeline-and-recovery-evidence.md): source-reported loader, startup, checkpoint, and exact-resume observations.

For full investigations start with the [case index](../../README.md#find-your-symptom); for measurement rules read the [methodology](../../docs/measurement-methodology.md).
